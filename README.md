## 🎯 چرا این پروژه؟

در پروژه‌های رسانه‌ای و تولید محتوا، ساخت دستی هر فاز و ایجاد ۶ الی ۸ تسک متوالی در گانت میزیتو و سپس اتصال خطوط وابستگی بین آن‌ها، فرآیندی زمان‌بر (۵ الی ۱۰ دقیقه برای هر ویدیو) و همراه با خطای انسانی (فراموشی اتصال لینک‌ها یا جا افتادن تسک‌ها) است.

این موتور اتوماسیون با تکیه بر توابع داخلی مرورگر:
- ساخت کامل فاز، تسک‌ها و اتصالات را به **کمتر از ۳ ثانیه** می‌رساند.
- اتصالات گانت را با دقت ۱۰۰٪ رسم می‌کند.
- بدون نیاز به سرور واسط، مستقیماً از نشست فعال کاربر در مرورگر بهره می‌برد.

---

## ✨ ویژگی‌های کلیدی

1. **شبیه‌سازی ریتم انسان (Human-paced Jitter):** اعمال مکث تصادفی حساب‌شده (۳۰۰ تا ۶۰۰ میلی‌ثانیه) بین هر درخواست API جهت حفظ سلامت اکانت و رفتار طبیعی.
2. **اتصال خودکار پیوندهای گانت:** ترسیم دقیق تمام فلش‌های پیش‌نیازی و وابستگی میان تسک‌ها به صورت متوالی و موازی.
3. **ممیزی خودکار دیتابیس (Post-flight Audit & Auto-Healing):** بررسی وضعیت پایگاه داده پس از اجرا و اتصال مجدد هر لینکی که به علت اختلال شبکه ثبت نشده باشد.
4. **مستقل از سرور جانبی (Zero Backend):** اجرا به صورت Client-side درون کنسول تب باز میزیتو.

## 🛠 نحوه کارکرد فنی (How It Works)

میزیتو یک وب‌اپلیکیشن است. هنگام حضور در تب گانت، سرویس‌های انگولار (`services` و `AppGanttManager`) در دسترس آبجکت `window` قرار دارند. این موتور:
1. ابتدا از وجود فاز (گروه) اطمینان حاصل کرده یا فاز جدید می‌سازد (`projects.ganttSaveGroup`).
2. تک‌تک تسک‌ها را اضافه کرده و به فاز منتسب می‌کند (`tasks.add` و `projects.ganttGroupAddTasks`).
3. شناسه‌های تسک‌های تولیدشده را به هم پیوند می‌زند (`projects.ganttTaskLinkAdd`).
4. با فراخوانی `projects.getGanttData` صحت پیوندها را با دیتابیس میزیتو اعتبارسنجی می‌کند.

## 🚀 راهنمای راه‌اندازی و استفاده

### گام ۱: تنظیم شناسه‌ها (`config.example.js`)
فایل `src/config.example.js` را باز کرده و شناسه‌های پروژه میزیتوی خود را در آن قرار دهید:
```javascript
window.MIZITO_CONFIG = {
  projectId: "شناسه_پروژه_شما",
  users: {
    CREATOR: "شناسه_کاربر_۱",
    EDITOR: "شناسه_کاربر_۲"
  },
  tags: {
    CALENDAR: "شناسه_برچسب_دلخواه" // اختیاری
  }
};
```
*(شناسه پروژه از آدرس مرورگر در صفحه گانت به سادگی قابل کپی است).*

### گام ۲: اجرا در میزیتو
1. در مرورگر خود وارد حساب **میزیتو** شوید و به **گانت پروژه** بروید.
2. کلید `F12` را فشار دهید و وارد تب **Console** شوید.
3. محتوای فایل `mizito_fast_batch.js` را کپی کرده و در کنسول اجرا (Enter) کنید.
4. با یک دستور ساده، ریل مورد نظر را ایجاد کنید:
```javascript
await window.createMizitoReel({
  reelNumber: "1",
  reelTitle: "Intro Video"
});
```
